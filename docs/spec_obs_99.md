# 观测向量 99 维（obs_version=3）

| 索引 | 维数 | 含义 |
|------|------|------|
| 0 | 1 | 己方开火阶段 ∈ [-1,1]：冷却中 `−剩余/90`；就绪后 `经过/90`（再计 1.5s 到 +1） |
| 1-6 | 6 | 敌方：局部 dx, dy, dθ/π, 进退 m∈{-1,0,1}, 转向 r∈{-1,0,1}, 同上开火阶段 |

维度公式：`1 + 6 + 4×bullet_slots + local_grid² + 3`，见 `tank_sim.observation.spec`。

相对 v2 的变化：

- 弹槽 8→10（容量对齐 5+5），威胁排序改为**固定身份槽**
- 子弹 `(vx,vy)` → 局部航向 `φ/π`（定速）
- 敌车 `(lvx,lvy,ω)` → 离散 `m,r`（定速进退/转向）
- 己方 / 敌方开火阶段双段编码：冷却 [-1,0]，就绪后再计 1.5s → (0,1]

历史堆叠（仅 MLP 训练）：`frame_stack × 99`，默认见 `configs/train/ppo_mlp_sb3.yaml`（16 帧 → 1584 维输入网络）。
